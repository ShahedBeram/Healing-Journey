## 📮 Postman Setup

1. Import the collection: `HealingJourney.postman_collection.json`
2. Import all environment files inside this folder.
3. Select the environment matching the role you want to test
   (Admin / Parent / Donor / Specialist / Recovered Child)
   from the environment dropdown (top-right in Postman).
4. Run the corresponding **Login** request first — the token
   will be saved automatically into the active environment.
5. You can now run any protected request under that role.
